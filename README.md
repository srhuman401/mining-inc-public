# Mining INC.

In Mining INC. you start with nothing but a rusty pickaxe on an island, the beginning of your mining company. You hit ore for resources, and then sell it. Overtime, you watch your mining company grow; with every drill you place, every worker you employ, and every rock you sell. 

# Exporting
After exporting the game:
-    Ensure that there is a folder called 'Downloads'
-    Copy these files from the source root into the exported executable folder: licenses.txt

# File Guide
Scripts and code are stored in /scripts/
Images are stored in assets/textures/ (Includes .aseprite/.ase source files with layers)
Data/GodotResources are stored in /data/
Most scripts are stored in scripts/game/
General enums are stored in /scripts/enum.gd

# Engine: Godot 4.7
